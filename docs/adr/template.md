# Template de ADR

Cada integrante escreve um ADR (Architecture Decision Record) sobre uma decisão já
tomada na Fase 1. Para criar o seu, copie o modelo abaixo para
`docs/adr/NNNN-titulo-curto.md`, usando o número reservado para você, e preencha as
quatro seções que o enunciado exige: contexto, decisão, alternativas e consequências.
